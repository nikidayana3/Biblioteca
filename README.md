Sistema de Gestión de Biblioteca

—Descripción
Esta es la descripcion del proyecto aplicación de escritorio en Java
con interfaz gráfica Swing, que permite gestionar el catálogo de libros de una biblioteca:
crear, mostrar, filtrar por autor y eliminar libros.

—Integrantes
-Gabriela Uribe
-Valentina Saavedra
-Nicol Restrepo

—Tecnologías utilizadas
- Java
- Java Swing (interfaz gráfica)
- Estructuras de datos: ArrayList, HashMap entre otros

—Funcionalidades
- Crear libros
- Mostrar todos los libros
- Filtrar libros por autor
- Eliminar libros

-Estructura del proyecto
- Libro.java — Clase modelo que representa un libro.
- Biblioteca.java — Clase que administra la colección de libros (agregar, eliminar, filtrar).
- VentanaPrincipal.java — Interfaz gráfica de la aplicación.
- Main.java — Punto de entrada de la aplicación.
